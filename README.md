## 📖 Overview

This repository serves as a personal collection of projects crafted to practice and reinforce fundamental concepts and operations within the NumPy library. It's designed for anyone looking to deepen their understanding of numerical computing in Python, particularly focusing on array manipulation, statistical analysis, and conditional logic using NumPy.

## ✨ Projects Included

This repository contains several Jupyter Notebook projects, each demonstrating different aspects and capabilities of the NumPy library.

### 1. Statistical Calculator (`project_1_stats_calculator.ipynb`)
This notebook focuses on generating random data and performing various statistical calculations using NumPy functions.
- **Key Concepts:** Array creation, random number generation, mean, median, standard deviation, variance, min, max, sum.

### 2. Pass/Fail Counter (`Project_2_Pass_Fail_Counter_.ipynb`)
This project demonstrates how to use NumPy for conditional data analysis, specifically counting occurrences based on a specific criterion (e.g., "Pass" or "Fail" states) within a dataset.
- **Key Concepts:** Boolean indexing, conditional logic with arrays, counting elements, array filtering.

## 🚀 Getting Started

To run these projects locally, you'll need Python and Jupyter Notebook installed.

### Prerequisites

-   **Python 3.x**
-   **pip** (Python package installer, usually comes with Python)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Anannya-Vyas/numpy-projects-.git
    cd numpy-projects-
    ```

2.  **Create a virtual environment (optional but recommended)**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies**
    ```bash
    pip install numpy jupyter
    ```

### Running the Notebooks

1.  **Start Jupyter Notebook**
    ```bash
    jupyter notebook
    ```

2.  **Open in browser**
    Your web browser should automatically open a new tab at `http://localhost:8888` (or similar).
    From the Jupyter interface, navigate to the `numpy-projects-` directory and open any `.ipynb` file.

3.  **Execute cells**
    Inside each notebook, you can run cells sequentially to see the code in action and understand the outputs.
